# 포트리스 서바이버 (프로토타입 v0.5)

포트리스식 포격(각도·파워·바람)과 서바이버식 웨이브 디펜스를 합친 웹 게임 프로토타입입니다.
오른쪽에서 몰려오는 적을 포격으로 막아내며, 레벨업 카드로 무기를 키워 웨이브 20 보스를 쓰러뜨리면 승리합니다.

## 플레이
- PC: 브라우저에서 `index.html`을 열거나 GitHub Pages 주소로 접속
- 모바일: 가로 화면으로 접속 (터치 버튼 자동 표시)

## 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | ← → | 왼쪽 아래 ◀ ▶ |
| 각도 | ↑ ↓ (Shift: 정밀) | 오른쪽 ▲ ▼ (톡 1°, 길게 누르면 연속) |
| 발사 | Space 또는 마우스를 누르고 떼기 | 발사 버튼을 누르고 떼기 |
| 카드 선택 | 1 · 2 · 3 또는 클릭 | 카드 터치 |
| 일시정지 | P | 오른쪽 위 II |
| 소리 켜기·끄기 | M | 오른쪽 위 ♪ |

## 규칙 요약
- 이동 중에는 재장전이 50% 느려집니다.
- 탱크와 적은 지형 경사에 맞춰 기울고, 포의 실제 발사 각도는 '포신 각도 + 차체 기울기'입니다. 오르막에서는 90°를 넘겨 뒤로 넘기는 빽샷도 가능합니다.
- 포격으로 생긴 구덩이는 적을 느리게 하고, 웨이브가 끝나면 지형이 원래대로 복구됩니다.
- 탱크 체력은 자동으로 회복되지 않습니다. 회복은 '긴급 수리' 카드뿐입니다.
- 5웨이브마다 보스가 나오고, 보스를 쓰러뜨려야 다음 웨이브로 넘어갑니다.
- 레벨업 능력 중 '자동 발사'를 고르면 주포가 가장 가까운 적을 스스로 조준해 쏩니다. 레벨이 오를수록 정확해집니다.
- 기지나 탱크가 무너지면 환생합니다. 가지고 있던 능력 하나를 골라 Lv1로 가지고 웨이브 1부터 다시 시작합니다.

## 구성
- 단일 파일 `index.html` (HTML5 Canvas + 순수 JavaScript, 외부 라이브러리 없음)
- 탱크·적·보스·배경·아이콘은 모두 코드로 그린 오리지널 그래픽이고, 효과음은 Web Audio로 실시간 합성합니다. 외부 이미지·사운드 파일이 없습니다.
